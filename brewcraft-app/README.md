# Brewcraft App (MVP Prototype)

A runnable Expo + React Native starter implementing core Brewcraft flows:
- Home recommendation
- Guided brew timer session
- Recipe library
- Ratio calculator tool
- Brew history with simple recommendation logic

## Run locally

```bash
cd brewcraft-app
npm install
npm run start
```

Then press:
- `i` for iOS simulator (macOS)
- `a` for Android emulator
- `w` for web

## Included methods
The product concept supports Espresso, Pour-over, AeroPress, French Press, Moka Pot, and Cold Brew. This starter includes sample recipes and structures to extend each method quickly.
